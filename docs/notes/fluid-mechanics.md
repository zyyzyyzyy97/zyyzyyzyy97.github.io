# 第一章 · 流体的性质

::: info 章节概览
这一章要回答两个问题：流体和固体到底差在哪，以及流体内部的摩擦（黏性）怎么定量。考试主要考定义和单位（填空）、牛顿与非牛顿流体（问答），以及平板、圆盘、圆柱缝隙里的黏性力计算。
:::

## 流体的定义与连续介质假设

::: tip 流体的定义（填空高频）
流体是在任何微小剪切力作用下都会发生连续变形的物质。换句话说，静止的流体不能承受剪切应力。
:::

连续介质假设把流体看成由连续分布的流体质点组成，忽略分子间隙，于是密度、速度、压强都可以写成空间与时间的连续函数。

## 黏性与牛顿内摩擦定律

牛顿内摩擦定律：`τ = μ · du/dy`

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| τ | 剪切应力 | Pa |
| μ | 动力黏度 | Pa·s |
| du/dy | 速度梯度 | s⁻¹ |

::: warning 易错点
动力黏度 `μ` 与运动黏度 `ν` 别混：`ν = μ / ρ`，单位是 m²/s。
:::

## 牛顿流体与非牛顿流体

- **牛顿流体**：黏度只与温度、压强有关，与剪切速率无关，如水、空气、甘油。
- **非牛顿流体**：表观黏度随剪切速率变化，如血液、泥浆、聚合物溶液。

## 表面张力与毛细现象

表面张力 `σ` 的单位是 N/m；毛细上升高度 `h = 2σ·cosθ / (ρ·g·r)`。

## 两平板间的流动（典型问题）

::: info 题型清单
给定板间距、相对速度与黏度，求剪切应力与所需拖曳力。注意速度线性分布、单位换算，以及上下两块板是否都在运动。
:::

## 复习重点

1. 定义与单位：密度、重度、动力黏度、运动黏度、体积模量。
2. 牛顿内摩擦定律的三种典型几何：平板、圆盘、圆柱缝隙。
3. 连续介质假设的适用条件与失效场景。
